# MSA-GoFuture

Итоговая проектная работа по курсу «Микросервисная архитектура» на примере платформы GoFuture.

Решение развивается последовательно: сначала монолит разделяется на доменные сервисы, затем добавляется событийная платформа, после чего проектируется глобальное развёртывание и аварийное восстановление. Артефакты каждого задания хранятся в отдельной директории.
