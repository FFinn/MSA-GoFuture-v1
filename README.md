# MSA-GoFuture

Итоговая проектная работа по курсу «Микросервисная архитектура» на примере платформы GoFuture.

Решение развивается последовательно: монолит разделяется на доменные сервисы, затем добавляется событийная платформа, после чего проектируются глобальное развёртывание, аварийное восстановление и многотенантная модель для партнёров. Артефакты каждого задания хранятся в отдельной директории.
